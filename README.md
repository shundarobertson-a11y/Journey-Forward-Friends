# Journey Forward Friends

Starter prototype for **Journey Forward Friends**, a worldwide platonic-friendship community being designed for cancer patients, cancer survivors, and people whose pets have or had cancer.

## Current prototype
This first version is intentionally simple:
- Responsive landing page
- Mission and audience sections
- Privacy/safety positioning
- Demo waitlist form
- No database and no collection of medical records

## Important product principles
- Platonic friendship, not dating
- Core browsing and matching intended to be free
- Do not request detailed medical records or treatment records
- Privacy, reporting, blocking, and moderation are launch priorities
- Do not sell personal health information

## Files
- `index.html` — page structure/content
- `styles.css` — visual design and responsive layout
- `script.js` — small interactive demo behavior

## Next build stages
1. Connect a real waitlist.
2. Add account creation and authentication.
3. Build friendship profiles with minimal, user-controlled information.
4. Add browse/search/matching.
5. Add friend requests and private messaging.
6. Add block/report/moderation tools.
7. Add privacy policy, terms, community guidelines, and age/safety decisions.
8. Add optional paid perks only after the free core experience works.

This is a prototype, not a medical service.
